# Sapaan Mahasiswa
- Top-level Container: `JFrame` (`SapaanMahasiswa`)
- Intermediate Container: `JPanel` (`panelUtama`, `panelTombol`)
- Atomic Component: `JLabel`, `JTextField`, `JButton`
- Layout: `BorderLayout`, `GridLayout`, `FlowLayout`
- Event Listener: `ActionListener` (`actionPerformed`) dan `WindowAdapter` (`windowClosing`)
